Katana Pro

During my time at Dauntless XR, our organization was partnered with Dell Technologies through their "Powered By Dell" initiative that highlighted small businesses that were creating unique and innovative use cases through the use of hardware produced by Dell Technologies. I was tasked with creating a demonstration application that would provide an engaging and user-friendly proof-of-concept that was displayed at the 2025 Dell Technology World Conference and reflected the type of work I was creating with our AI-powered object recognition software that was capable of running on mobile devices.





React and Tailwind CSS

Considering the limitations of the hardware available at the time, I selected the Meta Quest 3 for the best end user experience. The intuitive controls, head mounted display comfort, and onboard hardware of the Quest 3 allowed me the best combination of processing power and end user experience without sacrificing performance or image quality. Using a Dell-provided Lego set that contained 30 unique pieces, I was able to create an experience that was capable of detecting the individual bricks and associate them with the tasks I parsed from the instruction booklet, allowing me to tag and direct the user's attention to the bricks relevant to the current step they were on, thereby streamlining the assembly process.

Performance Metrics provided via Ultralytics

Next, I needed to select the AI architecture that would power the experience. By considering the performance limitations stated earlier, I chose the YOLOv11n Object Detection model from Ultralytics running on Unity Sentis on the backend for an inference engine. My model was trained for 500 epochs using synthetic data I generated from Lego models for accurate detections of the specific bricks included in the Dell-provided set while avoiding model bloat with unneccesary training. I was able to consistently acheive an average of 80-95% confidence on the individual bricks the model was trained to detect.

Docker and AWS Deployment

User contruction time was tracked during the application and recorded to a leaderboard that Dell event organizers were able to use for promotional prizes. I was able to make inferences using real time camera footage taken from the Quest's front-facing camera using the Meta Passthrough API while delivering an average frame rate of 65fps during inference.
