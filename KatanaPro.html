Katana Pro

In an effort to modernize the web-authoring platform, I was tasked with creating a fullstack web application to offer a no-code authoring solution to allow users to create XR guided workflows that mimicked the simplicity of a Google Form. The solution was to be containerized and deployed onto an AWS EC2 instance and allow users to view content in XR that was published to the platform. Workflows were either published to an organization for internal use or made publicly available for all users.





React and Tailwind CSS

I selected React and Tailwind CSS for the frontend application due to the stability and my own familiarity of the framework. Guided by mockups that were created in collaborated on in Figma, I created an interface that highlighted simplicity and ease of use.

Workflow Authoring

The no-code solution for authoring XR content.

PostgreSQL Database

Analytics Dashboard

Users could see how their content was being engaged with in real time.

I then created a backend application using Node.js running a PostgreSQL database to separate the workflows into public and private organization repositories. Furthermore, this allowed me to create engaging analytics dashboards for users to view how their content was being interacted with.

Docker and AWS Deployment

After containerizing the application using Docker, I deployed the solution to AWS and used NGinx to handle the proxies for domain management. The application is live at katanaxr.com and boasts an uptime of over 99.9%.
