Synthetic Data Generator

While producing XR experiences that were capable of object detection in real time, I found it necessary to develop a pipeline to produce accurate synthetic training data using 3D models and our existing Unity tech stack for situations where obtaining real world training photos and footage in the volumed needed for accurate training was impractical. Thus, the Synthetic Data Generator was born.





Unity 6 Editor

I had a fairly clear vision of my direction from the start, I had access to accurate 3D models, a Unity tech stack to work with, and a knowledge of how to generate the training data from inside the Editor. I quickly made an Editor tool with Unity 6 that was able to ingest models and output captured images directly to my Python training environment. On average, I was able to generate upwards of 20K+ unique training images from scratch in approximately 2-3 minutes per batch.

In order to create variance in the training data, I added parameters to the Editor tool that allowed me to freely manipulate values from the Inspector window. I could alter the position, rotation, and scale of the object, as well as the number of objects included into each image for advanced training. Furthermore, variables for background color, lighting conditions, and output size of the training data automated the variation of training data per image to add more complexity to train the model.

Labeling for YOLO Training

The final challenge was generating accurate labeling for the generated images. By using Unity's rendering engine, I was able to calculate the bounding box values and center point for each unique object rendered as well as assigning the class name for training the YOLO object detection model I was using at the time. Image labels were verified using my Python training environment and code I had written to test the individual images.
